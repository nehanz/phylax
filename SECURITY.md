# Security Policy

## Supported Versions
We actively maintain and provide security patches for the following versions of Phylax:

| Version | Supported |
|---|---|
| 0.1.x | :white_check_mark: |
| < 0.1.0 | :x: |

---

## Reporting a Vulnerability

The Phylax team takes security vulnerabilities seriously. If you discover a security flaw or vulnerability:

1. **Do not open a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or email the maintainers directly.
3. Include detailed steps to reproduce the issue:
   - Affected service and endpoint
   - Sample payload or request
   - Potential impact
4. Please give maintainers a reasonable window (up to 90 days) to investigate and patch the issue before any public disclosure.

We will acknowledge receipt of your vulnerability report within 48 hours and provide status updates as we develop a fix.
